## Sobre

Vitrine pessoal construída em Next.js para apresentar projetos técnicos de forma pública e profissional, mantendo confidencialidade de repositórios privados. Foco em demonstrar arquitetura, decisões técnicas e impacto de negócio.

Documentação técnica completa em [PROJECT_BRIEF.md](./PROJECT_BRIEF.md).

---

## Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Linguagem:** TypeScript 5
- **Estilização:** Tailwind CSS 4 com design tokens via CSS variables
- **Animações:** Framer Motion + Lenis (smooth scroll)
- **Tipografia:** Geist Sans, Pixelify Sans, JetBrains Mono (via next/font)
- **Deploy:** Vercel

---

## Como rodar

```bash
git clone https://github.com/gabrielle-git/portfolio-gabrielle.git
cd portfolio-gabrielle
npm install
npm run dev
```

Acesse `http://localhost:3000`.
